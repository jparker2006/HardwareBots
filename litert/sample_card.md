# cable swap

## 1. Find the port by its label
- **Do:** Find the target port by reading its label, not by counting ports.
- **Look for:** The label on the port matches the work order.
- **Why:** Port order differs between switch models, so counting lands you on the wrong port.
- **If skipped:** You unplug a live customer link.

## 2. Pull the old cable straight out
- **Do:** Press the latch and pull the old cable straight out.
- **Why:** Pulling at an angle bends the pins in the port. *(unconfirmed)*
- **Common mistake:** Yanking the cable without pressing the latch.

## 3. Insert the new cable with slack
- **Do:** Plug in the new cable and leave a small loop of slack before the tie point.
- **Look for:** A visible loop between the port and the cable tie.
- **Why:** Slack takes the strain off the connector when the door closes, so it doesn't work loose.
- **If skipped:** The connector works loose over a few weeks and the link drops.

## 4. Label both ends
- **Do:** Label both ends of the new cable with the port number.
- **Why:** So the next person can trace the cable without unplugging anything.
